# Data & Cloud Archive

Raw Sentinel-1 HyP3 interferograms (~20.9 GB) and MintPy HDF5 outputs (~537 MB) are archived on Google Drive: https://drive.google.com/drive/folders/1rClCma5LdWYK6mEfjorQSa0u7FlhU_Sh

  - `Step1_ROI_and_GroundTruth/` — Manually digitized Mansheya building footprints (`MA_00001`–`MA_00064`), Sentinel-1 SLC catalog, and historical collapse records (`alexandria_collapses.csv`).
  - `Step2_InSAR_mansheya_attarine/mintpy_outputs/` — Exported scatterer time series (`ps_points_mansheya_attarine.csv`, `.geojson`) and full MintPy SBAS stack (`mintpy_mansheya_attarine.zip`).
  - `Step2_InSAR_mansheya_attarine/hyp3_ifgs_by_year/` — Yearly archives (`2021`–`2024`) of the `441` ASF HyP3 `INSAR_ISCE_BURST` (`5x1` looks) interferograms.
